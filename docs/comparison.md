# How mStack compares

Short version: the popular skill stacks make your agent a better engineer. mStack takes you out of the
jobs you do not need to be in. They go together.

| | Superpowers | Matt Pocock's skills | ECC | mStack |
|---|---|---|---|---|
| What it is | A software development methodology for coding agents: spec, plan, subagents, review | Small composable engineering skills one engineer uses daily | An agent harness operating system: skills, rules, memory, security | Six skills about the person's time: ping me, ask once, work while I am away, find the look, keep improving it, present it where I am |
| Who it is for | Developers building software with an agent | Developers who want control and small pieces | Developers running several agents and harnesses | Anyone who delegates work to an agent, developer or not |
| Switches on by itself | Yes | Yes | Yes | Yes (a session start hook; tested on a clean install, see docs/evidence.md) |
| Agents | Many (Claude Code, Codex, Cursor, Gemini, Copilot and more) | Claude Code, Codex, Copilot, skills.sh | Claude Code, Codex, Cursor and more | Claude Code (plugin), Codex, Cursor; any other agent from a plain page (docs/agents.md) |
| Needs | The agent | The agent | The agent | Python 3, and Node plus Chrome only for the review loop and phone-width screenshots |
| Licence | MIT | MIT | MIT | MIT |

Use them together: Superpowers or Matt Pocock's skills for how the code gets written, mStack for what
happens around you while it does (you get pinged, you are asked once, the report arrives on your phone,
the next round runs overnight).

What mStack does not try to do: own the coding process, add memory or security layers, or ship hundreds
of skills. Six is the number, on purpose.

Checked 7 November 2026 from each repository's README. If this page is out of date, open an issue.
